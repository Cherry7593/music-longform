## 关键覆盖

- 升级前验证旧数据，保留字节一致、不可覆盖的备份；项目索引、旧素材路径和密钥密文不变。
- 多份历史目录必须选择；损坏旧数据不被跳过后当作空账户；显式用户目录优先。
- 音乐时长由 FFprobe 检测，预处理后复核；交叉淡化扣除重叠，不足目标时长拒绝视频导出。
- 未凑够目标时长也能试听已有连接处，不补静音、不循环、不制造目标结尾；完整导出仍被阻止。
- 直接拼接、淡出后淡入、平滑交叉淡化的曲目先后、音量包络、首尾淡化与预览一致性。
- 不同采样率/声道的输入；完整曲目两遍响度处理；静音分析结果为无穷值时不传入非法参数。
- 先裁切再结尾淡出；防削波不开启自动增益补偿，补偿限幅器延迟。
- 以进程实际输出时长更新分阶段进度，0–1 引擎进度正确转换为百分比；最终提交前不显示完成。
- 导出快照不被后续草稿编辑改变；项目切换/重启保留编排和成片记录；原始素材哈希不变。
- 实际音频/视频播放与进度拖动、另存为文件复制、窗口无横向溢出；另存为测试使用选定路径替代手动点击系统弹窗。
- 同时只能运行一个本地任务；取消等待本进程持有的子进程关闭，不影响另一条独立 FFmpeg；只清理本任务目录。
- 缺文件、损坏音频、缺少工具、不安全路径、目标不足、重复曲目、超出首数上限、短曲转场冲突、失败/取消/重启中断。

## 使用边界

本次合成已实测，没有视频功能验收阻塞。真实 Mureka/OpenAI 账号权限、AI 生成质量和实际扣费仍未进行付费调用验证。

视频依赖本地 FFmpeg / FFprobe；本次为 FFmpeg 9.0 Windows x64。网络共享路径不用于合成，当前成片提交要求同卷硬链接能力，建议本地 NTFS。程序不安装工具、不改原素材、不把目标不足自动变成循环视频。

存在第三方构建工具的 Zod 注释提示及 Python Playwright 的弃用提示；所有相应命令均以 0 退出。未修改第三方库来掩盖提示。
