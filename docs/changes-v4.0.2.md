# V4.0.2：模板下载与批量粘贴创建条目

## 使用

1. 在当前生成项目的音乐或图片页面点击“下载音乐模板”或“下载图片模板”，通过系统保存对话框保存 UTF-8 `.md` 文件。取消保存不报错。
2. 将模板交给外部 AI，并自行说明主题、数量。软件不接入聊天模型、不访问外部链接。
3. 点击“批量导入提示词”，只粘贴 AI 按 v1 模板返回的结果，不粘贴模板说明；不支持导入文本文件。
4. 解析后核对内容，可修改名称、提示词、歌词或移除条目；按原文剩余顺序创建。音乐、图片不可混用。
5. 复用现有条目表单，逐条选择已添加 API/模型。展开“统一参数”并显式点击“应用到本次全部条目”，只同步参数，不覆盖名称、提示词、歌词。导入期间不刷新模型或测试连接。
6. 点击“创建 N 个条目”。仅追加未提交草稿，不产生远端请求。之后由用户自行全选并使用原生成确认流程。

没有 API 或参数未完善也可保存内容合法的草稿；实际生成仍受原厂商限制。未填写名称时不把编号当曲名。取消/关闭需一次放弃确认，不创建条目；返回原文会提示放弃预览编辑并要求重新解析。

## 边界与安全

- 原样复用 `docs/templates/音乐提示词模板.md`、`docs/templates/图片提示词模板.md`；构建时嵌入主进程，不在安装后读取源码 docs 目录。
- 固定 v1 标题与字段协议，支持 BOM、CRLF/LF/CR、前后空行和单层空/md/markdown代码围栏。错误保留原文，并给出原始行号、条目编号和原因；没有部分解析落盘。
- 每次1–500条；原文UTF-8最多2MiB，配置后的批量草稿负载同样限2MiB。名称500、提示词/歌词32000字符为草稿上限，不冒充厂商生成上限；超限报错，不截断。
- 多行正文和歌词内部段落/空格保留；重复提示词仅提醒，不去重。不执行或渲染文本里的HTML、脚本，也不读取其网址或路径。
- 当前弹窗绑定原生成项目与素材类型，背景导航由现有inert/focus-trap阻止；主进程再次核对项目、类型、适用已添加API、容量及字段。
- 一个WorkBenchDB事务追加本批条目及项目entryIds；稳定批次ID、内容指纹和条目序号防止重入。回复中断先查询已保存结果，未知时只核对，不自动重建。取消、结构错误及保存失败不暴露半批新草稿；已有redo意图按原批恢复。
- 生成列表和提交快照按项目entryIds顺序读取，重启不按随机UUID文件排序打乱本批内容。旧条目、旧API/凭据和素材不改写。
