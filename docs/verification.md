## 覆盖的关键行为

- 双提示词独立保存，生成更新不覆盖尚在编辑的另一侧输入。
- 按首数生成，显式请求 `n=1`，串行队列、防止重复点击、失败暂停及停止未提交项。
- 创建请求超时或网络状态不明不自动重发；已知任务只恢复查询/下载；没有任务 ID 时明确提示状态未知。
- 已成功素材保留，生成图片不改变音乐，项目切换前保存编辑。
- Windows 系统加密实际集成；项目与公开设置不含测试密钥明文。
- 密钥、权限、余额、429、超时、格式错误等模拟服务响应。
- 下载大小/时间/协议限制、拒绝私网目标、路径越界和符号链接检查。
- 本地音频实际播放、拖动进度、单音轨播放，保留曲目与时长。
- PNG 实际解码预览、图片放大与另存为；保存/打开对话框在 E2E 中以选定的测试路径代替手动点击。
- 中文与空格路径、重启保留项目与密钥、既有任务恢复、新保存目录不搬移旧项目。
- IPC 来源与参数校验，渲染页面无法直接取得 Node `require`、`process` 或通用 IPC。
- 打包后 `app.isPackaged=true`；即使设置测试环境变量，仍保持 `testMode=false`。

## 边界与剩余验收

所有生成测试均使用模拟接口，未发起真实付费生成，也未使用真实 API 密钥。真实账号可用性、模型权限、网络连通、生成质量与实际扣费尚待用户在设置中配置凭证后验证。建议首次分别生成 1 首与 1 张。

打包产物的应用程序已实际启动检查；便携版自解压启动器由 electron-builder 生成。没有进行代码签名，Windows 可能显示未知发布者提示。

构建有来自 Zod 依赖注释的 Rollup 提示，不影响构建结果；没有为消除提示而修改第三方依赖。内置浏览器截图工具未响应，视觉自动检查改用实际 Electron 窗口的 Playwright/CDP，截图已保存。
