# V4 诊断、取消与恢复

## 在哪里查看

进入“批量合成”，展开所属项目的执行批次，点击失败任务的“诊断”。每次尝试保留独立记录，可切换历史并复制诊断；重新尝试不覆盖前一次证据。

诊断位于应用数据目录的 `diagnostics/<诊断UUID>.json`，独立于会被清理的临时工作目录。项目删除不清理诊断文件，素材使用台账也不依赖诊断存在。

## 字段与可信范围

| 字段 | 含义 |
|---|---|
| taskId / attemptId | 视频任务与此次尝试的独立标识 |
| stage | tools工具 / probe素材探测 / audio音频处理 / mix混音 / encode编码或封装 / validate校验 / publish发布与登记 |
| assetId / assetName | 确认属于素材处理步骤时的关联素材；未知时不编造 |
| toolVersion / encoder | 实际工具、编码器证据；没有取得则留空 |
| exitCode / osCode | 子进程退出码或系统错误码；没有证据则留空 |
| stderr | 最多16KiB的脱敏错误输出；不是完整控制台录屏 |
| category / message / suggestion | 依据明确证据分类及可执行处理建议 |

Authorization、API Key、令牌与HTTP地址会脱敏。复制前仍应检查素材名称、本地目录和个人信息；软件不会自动上传诊断。不可根据一个通用退出码断言“素材损坏”。无法确认时显示“原因未确定”。

## 常见问题

- **找不到工具或缺少必要功能**：在“设置 → 视频工具”确认FFmpeg/FFprobe及编码器、滤镜。不要无休止原样重试。
- **素材不可读或指纹改变**：核对相关文件是否被移动、替换或被重定向。恢复原字节后刷新；不同内容应作为新素材重新选材/规划。
- **权限或安全发布失败**：检查本地保存权限、占用与同卷硬链接支持。不会通过覆盖已存在文件来“修好”。原素材保持不变。
- **磁盘空间不足**：先释放空间或降低并行数。静态缓存、中间音轨和最终MP4需要的空间不同；最终文件很小不代表处理不需要临时空间。
- **硬件初始化失败**：工具检查会真正短编码、探测与解码。编码器名字出现不等于可用；软件提供回退路径，不自动安装驱动或修改设备。
- **成片已发布，登记未完成**：保留文件和回执，重新打开或继续原任务，让本地登记/使用对账完成。不要删除回执后重新渲染，避免重复成片与记账。

## 合成任务的控制边界

- 单任务取消只作用于该任务；批次取消只作用于该批次；项目取消只作用于该合成项目。
- 批次“暂停”允许已启动的视频结束，停止尚未启动的项；全局池中的其他项目继续运行。
- 普通素材/单任务错误不无差别取消其他任务；共享工具或磁盘故障会暂停等待中的相关任务。
- “继续”需要确认，只处理未成功项。成功发布使用同一任务/发布ID对账，重启、重试和另存为不重复增加使用次数。
- 重启后未完成任务保持暂停/中断，不自动重跑。编码中断没有中间帧续编，手动重试重新编码。
- 临时目录只清理该任务自己的 `.work-<UUID>`，不按进程名结束其他FFmpeg，也不清理其他项目/进程的文件。

## 生成请求不是视频任务

生成属于不同队列：每条目一次创建，默认串行；远端厂商任务无法用本地取消信号撤回。

| 状态 | 安全操作 |
|---|---|
| 尚未提交、暂停等待 | 统一确认后继续，或停止后续未提交请求 |
| 已有远端ID | 恢复原平台、原连接的查询/保存，不再次创建 |
| 已有部分返回结果 | 保留全部版本身份及成功资产，补存缺失结果 |
| 受理未知且无远端ID | 先核对原平台队列/账单；绝不自动重发 |
| 明确放弃追踪 | 用户确认后停止本地追踪，不代表退款或远端已取消 |

切换项目不改变任务归属。未完成、未知或可恢复请求阻止删除项目/连接；更换地址不得静默使用新来源查询旧任务。关闭应用不停止用户ACE-Step服务，也不保证厂商已受理请求不收费。

## 验证边界

`tests/unit/composition-v4.test.ts` 用可控渲染替身验证跨项目取消、失败隔离、共享磁盘暂停、诊断脱敏与多次尝试、成功不重跑，以及发布后登记失败的幂等恢复。它不证明视频质量或实际性能。

真实HTTP、媒体保存、并行65秒成片、完整解码、入库/使用/删除/重启由 `tests/integration/workbench-flow.test.ts` 等集成测试覆盖；小时级同条件计时和完整桌面/打包验收另记在V4验收文档，不用历史版本结果代替。
